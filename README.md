# Harmony Business Suite

Reconstruis cette application à partir de l’archive jointe. C’est un progiciel de gestion francophone CodeIgniter, organisé autour de modules : Administration/RH (employés, congés, présences, salaires, utilisateurs/rôles), Données (clients, fournisseurs, achats, ventes, budgets), Stock, Charroi/véhicules et carburant, Communauté (membres, associations, coopératives), Électronique/mobile money, projets/programmes/partenariats, suivi, rapports et archives. Crée une application web moderne et cohérente avec tableau de bord, navigation latérale structurée, listes recherchables, formulaires/modales, données de démonstration et parcours fonctionnels. Active Lovable Cloud afin de pouvoir persister les données et gérer les utilisateurs. Privilégie une base solide avec les modules Administration/RH, Données, Stock, Charroi, Communauté et Rapports pleinement représentés, et les autres accessibles depuis la navigation.
